# Reference index

One row per document. PDFs live in `references/{papers,patents,reports}/` and are
**not committed** (copyright); this index is. `references/text/` holds `pdftotext`
output for grep, also uncommitted.

Status: `local` = PDF on disk · `paywalled` = DOI only, get via institutional access ·
`web` = HTML/tool, no PDF · `missing` = could not locate.

Role: `validation` = reproduce its cost table · `method` = accounting template ·
`benchmark` = titer/price priors · `product` = BLG/OVA-specific data · `patent`.
